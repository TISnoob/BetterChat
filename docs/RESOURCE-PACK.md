# BetterChat flag resource pack

The generated pack is `resource-pack/BetterChat-Flags.zip`. It maps 249 ISO country flags and a rectangular Earth world-map flag to private-use glyphs in the `betterchat:flags` font. BetterChat's own Adventure messages can style the glyph with that font, and the optional tab/nametag components use it when `flags.resource-pack.use-glyphs` is enabled.

## Generate

The country PNGs and complete Twemoji graphics license are checked in. The pack generator creates the Earth flag as a 3:2 rectangle and builds the font map. With Python 3 and Java 25 installed, regenerate the pack with:

```shell
python3 resource-pack/generate_pack.py
```

Or run `./gradlew assemble`, which generates the pack along with the plugin jars. To refresh upstream images explicitly, run `python3 resource-pack/fetch_flags.py` and then regenerate. That fetcher reads the current Java ISO country list, downloads Twemoji images, and reports any missing emoji sequence.

The font map assigns each two-letter country code a stable private-use code point. `EARTH` has its own rectangular glyph and is BetterChat's default flag. Iran uses the current official green-white-red flag with the red emblem. `ZZ` (unknown/hidden) falls back to the globe emoji rather than a country glyph. Without the resource pack, Minecraft's built-in globe emoji remains the Earth fallback.

## Host and send

Upload the ZIP to a public HTTPS server that returns the ZIP directly. The Minecraft client needs to reach the URL; a path on the game server is not enough. Compute the SHA-1 after the final upload/build:

```shell
sha1sum resource-pack/BetterChat-Flags.zip
```

Set `flags.resource-pack.enabled`, `url`, and `sha1` in Paper's config. Turn on `use-glyphs` after the pack is available to players. Leave `required: false` to make pack acceptance optional. Repeat the Paper config on all backends so players get the same font regardless of server.

The generated `pack.mcmeta` declares resource pack formats 88.0 through 97.1, covering Minecraft Java 26.2 (format 88.0) and 26.3 (format 97.1). It uses the modern `min_format` and `max_format` metadata fields so both clients can load the same pack.

## Using placeholders

`%betterchat_flag_glyph%` and `%betterchat_global_flag_glyph%` output the glyph characters. Placeholders are plain strings; a formatter must render them in the `betterchat:flags` font. MiniMessage in BetterChat's own renderer uses Adventure font styling directly. Other plugins vary, so use their font/Adventure-component support when available or keep the Unicode emoji fallback.
